## Composite sets vs 7-ply hardwood

Fiberglass and graphite sets in this catalog put a composite face over a polymer or honeycomb core. The Activator is **7-ply hardwood** with a plastic edge guard. Weekly rec players leave the wood set once the session is longer than a driveway tryout. The reasons are feel, not a lab sheet. **None of the four set listings print an ounce weight**, so this page does not invent one.

Wood is the honest ultra-budget baseline: absolute beginners, a backyard, a camp weekend, or anyone who wants the cheapest way to see if they like the sport. The Activator description says that directly, and the skill line is **beginner**. It includes **two X-40 outdoor balls**, so the first rally can happen the day the box arrives.

The same listing is a poor weekly paddle. The sweet spot is small and the bounce is dull next to fiberglass or graphite over a honeycomb core. Off-center contact on that small face is what tires the wrist and forearm over a rec block. Neighbors hear a sharper crack from solid wood than from a core. This catalog does not print decibels for these sets. If a muted feel is the whole job, use [quiet paddles](/guides/best-quiet-pickleball-paddles). None of these set listings print a quiet line or a vibration-dampening line.
